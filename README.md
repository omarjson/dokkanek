# دكّانك — Dokkanek

منظومة مبيعات ليبية **مفتوحة المصدر** (MIT): نقطة بيع، مخزون، موردون ومشتريات، زبائن وديون وآجل، مصروفات، مناديب توصيل، صيانة هواتف، موظفون وحضور ورواتب، تقارير ولوحة تحكم، سجل أمني — واجهة **عربية RTL** خفيفة.

## المميزات

- نقطة بيع: نقدي / بطاقة / تحويل / آجل / توصيل + فواتير انتظار ومعلقة
- أصناف: إضافة/تعديل/حذف/أرشفة، مفضلة ★، تصفير كميات، باركود وطباعة ستيكر، رقم قديم للترحيل
- تنبيهات المخزون المنخفض + حركات مخزنية لكل تغيير
- موردون + فواتير شراء تزيد المخزون تلقائيا
- زبائن + سقف آجل + سداد جزئي على فاتورة أو على الحساب
- مناديب: مهام توصيل + تحصيل عند التسليم
- صيانة: استلام → فحص → انتظار قطع → جاهز → تسليم + قطع غيار + تحصيل
- موظفون: حضور/انصراف بزر واحد + مستحق تلقائي من الدقائق + عمولات
- سجل أمني لكل حركة + إعدادات الهوية (الاسم/اللون/الهاتف تظهر في الفواتير)
- فروع ومخازن متعددة من اليوم الأول (كل جدول حركي فيه فرع)

## التشغيل المحلي (بدون أي دفع)

```bash
npm install
npm run setup   # تجهيز قاعدة البيانات + بيانات تجريبية
npm run dev     # افتح http://localhost:3000
```

حسابات التجربة:

| المستخدم | الدور | كلمة المرور |
|---|---|---|
| admin | مدير النظام | admin123 |
| cashier | كاشير | 1234 |
| courier | مندوب | 1234 |
| tech | فني | 1234 |

> تنبيه أمني: الدخول الحالي للتجربة والتطوير. قبل أي تشغيل حقيقي ببيانات محل فعلي يجب تقوية المصادقة (تشفير جلسات، حماية CSRF، نسخ احتياطي).

## البيانات التجريبية

`npm run seed` يحمل: 3 فروع (طرابلس/بنغازي)، 14 صنفا، زبائن وموردين، فواتير بيع وشراء، مصروفات، تذاكر صيانة، موظفين — كلها وهمية بأسماء عامة.

## البنية

- Next.js 14 + TypeScript + Tailwind (عربي RTL)
- Prisma + SQLite محليا (تتحول لـ PostgreSQL للإنتاج بدون تغيير الكود)
- نفس الكود يشتغل سحابيا أو على كمبيوتر المحل
